# customer_churn_prediction_system
 Customer Churn Prediction System
# Overview

This project is a Customer Churn Prediction System developed in Python using a Jupyter Notebook. The project simulates a simple customer churn analysis by applying Python fundamentals to customer subscription data. It demonstrates how basic programming concepts can be used to analyze customer behavior and determine whether a customer is at risk of churning based on predefined business rules.

# Project Objectives

By completing this project, I was able to:

- Create meaningful variables.
- Select appropriate data types.
- Perform arithmetic calculations.
- Update values using assignment operators.
- Compare values using comparison operators.
- Combine business rules using logical operators.
- Display information in a clear and professional format.
- Develop problem-solving skills using Python fundamentals.

# Technologies Used

- Python
- Jupyter Notebook

# Project Features

- Stores customer information using appropriately named variables.
- Performs calculations on customer subscription and usage data.
- Applies comparison and logical operators to evaluate customer behavior.
- Determines whether a customer is likely to churn based on defined business rules.
- Displays customer information and prediction results in a clear, readable format.
